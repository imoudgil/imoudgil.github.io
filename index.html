NeuroSync

C++20 · SITL motion engine
C++20 POSIX Threads Unix Sockets Quintic Splines

Producer–consumer engine bridging a slow Python policy (~1 Hz) to a 1000 Hz real-time control loop via IPC and trajectory interpolation.

  • TrajectoryBuffer (deque + mutex + condition_variable); consumer uses non-blocking tryPop() to keep RT loop off the wait path
  • Closed-form quintic spline solve for C²-continuous position/velocity/acceleration; sleep_until on steady_clock for 1 ms ticks
  • Newline-framed JSON over AF_UNIX with partial-read reassembly — zero third-party deps

Growth & Risk Analytics

Python · Experimentation + causal + fraud
Python SQL scikit-learn CUPED DiD

End-to-end growth and risk pipeline on synthetic fintech data with known ground truth: SQL warehouse, randomised experiment, observational causal study, and cost-aware fraud model.

  • 60k clients and 200k transactions in SQLite; CUPED recovers a +$18.88 deposit lift (truth +$18) with 80.8% variance reduction
  • Propensity-matched difference-in-differences recovers +$25.54/mo vs a naive +$126 (about 5× too high)
  • Fraud classifier: PR-AUC 0.134, cost-optimal threshold cuts expected loss 63%
